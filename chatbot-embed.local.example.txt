Copy this entire file's content into a new file named "chatbot-embed.local.txt"
(same folder as this one — the project root), then replace everything below
with the real snippet copied from your chatbot's Channels → Website tab in
the LogicMate dashboard. Paste it exactly as copied — nothing to edit, no
quotes to escape, no code to touch. Save, then run `npm run dev`.

That file is gitignored, so your real embedKey never gets committed.
